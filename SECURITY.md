# Security Policy

This is the default security policy for the repositories of the
[TETRA-2023](https://github.com/TETRA-2023) organisation. A repository with its own `SECURITY.md` follows
that file instead, which may add its scope.

## Reporting a vulnerability

Do not open a public issue, discussion or pull request about a vulnerability.

Open a private security advisory on the affected repository: **Security → Report a vulnerability**, or
`https://github.com/TETRA-2023/<repository>/security/advisories/new`. Include:

- the affected repository and commit, version or image digest;
- what an attacker can do, and under which configuration;
- the steps to reproduce.

The report stays visible only to you and the maintainers until a fix is published.

## Third-party code

Some repositories are forks or copies of other projects; their README names the origin. If the issue is in
code shared with that project, please report it to the original project as well.
